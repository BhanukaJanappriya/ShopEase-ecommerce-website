# ShopEase 🛍️

**ShopEase** is a modern, premium, and fully responsive e-commerce website built using HTML, CSS, and JavaScript. Featuring a curated pink-themed aesthetic, sleek glassmorphic UI elements, interactive checkout systems, and a complete blogging platform, it delivers a state-of-the-art online shopping demonstration.

---

## ✨ Features

* **Refined Pink Color Theme & Branding:** Features a custom minimal pink-themed logo and favicon, with all primary UI accents styled around a modern pink theme (`--salmon-pink`).
* **Sleek Glassmorphic Hero Banners:** Homepage slides are styled with premium glassmorphic text content overlays (backdrop-blur, border gradients, and soft shadows) for maximum visibility and high-end aesthetics.
* **Interactive Checkout Modal & Local DB Storage:** Clicking "Add to Cart" triggers a mock real-world checkout modal where users can enter input details. All transactions/inputs are recorded and stored in a local Web Storage database.
* **Redesigned Blog & Detail Pages:** Includes a fully redesigned, sleek `blog.html` page featuring a structured card grid and featured posts, along with dynamic `blog-detail.html` pages for complete reading.
* **Micro-Animations & Visual Polish:** Smooth fade-ins, hover states, scroll animations, and entry effects are integrated throughout the site for a premium interactive feel.
* **Responsive Design:** Optimized for mobile, tablet, and desktop screens with custom responsive layouts.
* **Multi-currency & Language Support:** Options to switch between LKR (Sri Lankan Rupees) and USD, and English, Sinhala, and Tamil languages.
* **Announcements & Notifications:** Real-time purchase toast notifications and a top bar promo banner (e.g., free shipping).

---

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and markup of the web application.
* **CSS3:** Styling and design, including CSS custom properties (variables), responsive layout grids, flexbox, glassmorphic effects, and transitions.
* **JavaScript:** Interactivity, modals, dynamic checkout forms, local database storage, and navigation routing.
* **Ionicons:** Modern SVG icon pack used across the interface.
* **Google Fonts (Poppins):** Premium clean typography.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

You only need a modern web browser to view and interact with the project.

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/BhanukaJanappriya/ShopEase-ecommerce-website.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd ShopEase-ecommerce-website
   ```

3. **Open the site:**
   Double-click or open `ShopEase/index.html` in your web browser.
